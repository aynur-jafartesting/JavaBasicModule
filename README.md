#  JavaBasicModule

A collection of hands-on Java exercises covering the language fundamentals — from variables to switch expressions.

Built while learning core Java concepts through practice.

---

## 📚 Topics Covered

### 🔹 Getting Started
- `HelloWorld.java` — the classic first program

### 🔹 Variables & Data Types
- `Task01_Variables.java` — declaring and assigning variables
- `Task01_Variables_Errors.java` — common compiler errors explained
- `Task02_PrimitiveTypes.java` — all 8 primitive types, overflow, precision issues

### 🔹 Operators
- `Task03_ArithmeticOperators.java` — `+ - * / %`
- `Task03_AgeCheck.java` — logical operators (`&&`, `!`)
- `Task03_DivisibilityCheck.java` — combined conditions
- `Task03_IncrementDecrement.java` — prefix vs postfix (`++x` vs `x++`)

### 🔹 Type Casting
- `Task04_BoundaryCasting.java` — overflow when casting `int → byte`
- `Task04_ChainedCasting.java` — implicit widening casts
- `Task04_CharToIntCast.java` — `char ↔ int` conversion
- `Task04_DoubleToIntCast.java` — truncation vs rounding

### 🔹 User Input (Scanner)
- `Task05_SimpleCalculator.java` — basic arithmetic from input
- `Task05_RectangleCalculator.java` — area & perimeter calculator
- `Task05_ScannerTrapDemo.java` — the classic `nextInt()` + `nextLine()` bug
- `Task05_SurveyForm.java` — mixed input types

### 🔹 Strings
- `Task06_CapitalizeWord.java` — string formatting
- `Task06_EmailValidator.java` — basic validation logic
- `Task06_EqualsVsDoubleEquals.java` — `==` vs `.equals()`
- `Task06_ImmutabilityDemo.java` — proving Strings are immutable
- `Task06_NameAnalyzer.java` — string methods in practice

### 🔹 Conditionals
- `Task07_AgeAccessCheck.java`, `Task07_EvenOddCheck.java`, `Task07_FindMaxOfThree.java`, `Task07_LoginSimulation.java`, `Task07_NumberSignCheck.java`, `Task07_TicketPriceCalculator.java`

### 🔹 Arrays
- `ArraysTask1.java` → `ArraysTask8.java` — iteration, searching, min/max, reversing, duplicates

### 🔹 Loops
- `LoopsTask1.java` → `LoopsTask8.java` — `for`, `while`, `do-while`, FizzBuzz, prime check, patterns

### 🔹 Methods
- `MethodsTask1.java` → `MethodsTask8.java` — overloading, recursion, working with arrays

### 🔹 Switch Statements
- `SwitchTask1.java` → `SwitchTask5.java` — classic switch, fall-through, switch expressions (`->`)

### 🔹 Extras
- `Calculator.java` — simple four-operation calculator
- `CutEdedler.java` — printing even numbers
- `Telebeler.java` — looping through a list of names

---

## 🛠️ Tech Stack

- **Language:** Java (JDK 21)
- **Concepts:** OOP basics, control flow, collections fundamentals, I/O
